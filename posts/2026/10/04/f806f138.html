可以利用这个方法, 将线性递推数列的阶数推广到更高.

从算子的角度来看

现在重新叙述一下我们的问题: 考虑初始条件

f0(x)=x\begin{aligned} f_{0}(x) = x \end{aligned} f0​(x)=x​

以及迭代关系

fn+1(x)=fn(11+x2)\begin{aligned} f_{n + 1}(x) = f_{n} \left( \frac{1}{\sqrt{1 + x^{2}}} \right) \end{aligned} fn+1​(x)=fn​(1+x2​1​)​

证明或求解: 当 n⩾1n \geqslant 1n⩾1 时, 通项为

fn(x)=Fn+Fn−1x2Fn+1+Fnx2\begin{aligned} f_{n}(x) = \sqrt{\frac{F_{n} + F_{n - 1}x^{2}}{F_{n + 1} + F_{n}x^{2}}} \end{aligned} fn​(x)=Fn+1​+Fn​x2Fn​+Fn−1​x2​​​

现在定义

H(x)=11+x2\begin{aligned} H(x) = \frac{1}{\sqrt{1 + x^{2}}} \end{aligned} H(x)=1+x2​1​​

那么有

f1(x)=H(x)\begin{aligned} f_{1}(x) = H(x) \end{aligned} f1​(x)=H(x)​

迭代关系为

fn+1(x)=fn[H(x)]=fn−1{H[H(x)]}\begin{aligned} f_{n + 1}(x) = f_{n} [H(x)] = f_{n - 1} \{H[H(x)]\} \end{aligned} fn+1​(x)=fn​[H(x)]=fn−1​{H[H(x)]}​

我们定义

H∘n(x)=H(H(H(⋯H(x)⋯ )))⏟n times\begin{aligned} H^{\circ n}(x) = \underbrace{H\bigl(H\bigl(H(\cdots H(x)\cdots)\bigr)\bigr)}_{n \, \text{times}} \end{aligned} H∘n(x)=ntimesH(H(H(⋯H(x)⋯)))​​​

表示 nnn 个 HHH 映射的嵌套. 在这样的记号下, 有

fn+1(x)=fn−1[H∘2(x)]=fn−2[H∘3(x)]=⋯=f1[H∘n(x)]=H∘(n+1)(x)\begin{aligned} f_{n + 1}(x) = f_{n - 1} [H^{\circ 2}(x)] = f_{n - 2} [H^{\circ 3}(x)] = \cdots = f_{1} [H^{\circ n}(x)] = H^{\circ (n + 1)}(x) \end{aligned} fn+1​(x)=fn−1​[H∘2(x)]=fn−2​[H∘3(x)]=⋯=f1​[H∘n(x)]=H∘(n+1)(x)​

也就是说

fn(x)=H∘n(x)\begin{aligned} f_{n}(x) = H^{\circ n}(x) \end{aligned} fn​(x)=H∘n(x)​

于是有

fn+1(x)=H[fn(x)]=11+[fn(x)]2\begin{aligned} f_{n + 1}(x) = H[f_{n}(x)] = \frac{1}{\sqrt{1 + [f_{n}(x)]^{2}}} \end{aligned} fn+1​(x)=H[fn​(x)]=1+[fn​(x)]2​1​​

此时, 自然的想法是, 对两侧进行平方. 因为从第一项开始, 每一项都为正, 因此无需考虑正负号的问题

[fn+1(x)]2=11+[fn(x)]2\begin{aligned} [f_{n + 1}(x)]^{2} = \frac{1}{1 + [f_{n}(x)]^{2}} \end{aligned} [fn+1​(x)]2=1+[fn​(x)]21​​

这正是我们前面得到的式子.

初值和极限

我们考虑递推关系

zn+1=11+zn\begin{aligned} z_{n + 1} = \frac{1}{1 + z_{n}} \end{aligned} zn+1​=1+zn​1​​

选定初值满足

z0⩾0\begin{aligned} z_{0} \geqslant 0 \end{aligned} z0​⩾0​

可以通过压缩映射的方法, 证明其是 Cauchy 列. 因此假定极限为 LLL, 则有

L=11+L\begin{aligned} L = \frac{1}{1 + L} \end{aligned} L=1+L1​​

为方便, 记黄金分割比为

φ=5+12\begin{aligned} \varphi = \frac{\sqrt{5} + 1}{2} \end{aligned} φ=25​+1​​

于是解得

L1=−φL2=1φ=5−12\begin{aligned} L_{1} = -\varphi \qquad L_{2} = \frac{1}{\varphi} = \frac{\sqrt{5} - 1}{2} \end{aligned} L1​=−φL2​=φ1​=25​−1​​

因为数列的每一项都是非负的, 所以有

lim⁡n→∞zn=1φ\begin{aligned} \lim_{n \to \infty} z_{n} = \frac{1}{\varphi} \end{aligned} n→∞lim​zn​=φ1​​

现在考虑初值的影响. 假定有两个不同的初值

z0=aw0=b\begin{aligned} z_{0} = a \qquad w_{0} = b \end{aligned} z0​=aw0​=b​

它们都大于0, 且满足相同的递推关系. 于是

∣zn+1−wn+1∣=∣zn−wn∣(1+zn)(1+wn)\begin{aligned} |z_{n + 1} - w_{n + 1}| = \frac{|z_{n} - w_{n}|}{(1 + z_{n})(1 + w_{n})} \end{aligned} ∣zn+1​−wn+1​∣=(1+zn​)(1+wn​)∣zn​−wn​∣​​

幸运的是, 分母是可以放缩的. 考虑

0<z1=11+a<1\begin{aligned} 0 < z_{1} = \frac{1}{1 + a} < 1 \end{aligned} 0<z1​=1+a1​<1​

继续迭代

0<12=11+1<1z1+1<1\begin{aligned} 0 < \frac{1}{2} = \frac{1}{1 + 1} < \frac{1}{z_{1} + 1} < 1 \end{aligned} 0<21​=1+11​<z1​+11​<1​

因此, 当 n⩾2n \geqslant 2n⩾2 时, 有

12<zn<1\begin{aligned} \frac{1}{2} < z_{n} < 1 \end{aligned} 21​<zn​<1​

于是

(1+zn)(1+wn)>(1+12)(1+12)=94\begin{aligned} (1 + z_{n})(1 + w_{n}) > \left(1 + \frac{1}{2}\right) \left(1 + \frac{1}{2}\right) = \frac{9}{4} \end{aligned} (1+zn​)(1+wn​)>(1+21​)(1+21​)=49​​

从而得到

∣zn+1−wn+1∣<49∣zn−wn∣<⋯<(49)n−2∣z2−w2∣\begin{aligned} |z_{n + 1} - w_{n + 1}| < \frac{4}{9} |z_{n} - w_{n}| < \cdots < \left( \frac{4}{9} \right)^{n - 2} |z_{2} - w_{2}| \end{aligned} ∣zn+1​−wn+1​∣<94​∣zn​−wn​∣<⋯<(94​)n−2∣z2​−w2​∣​

这表明, 一开始有差别的两个数列, 每次迭代差值都会缩小 4/94/94/9 以下, 从而数列的极限不依赖与初值. 当然, 会依赖于初值的正负性.

第一个三角恒等式的证明

最后, 我们来证明下

cos⁡arctan⁡x=11+x2\begin{aligned} \cos \arctan x = \frac{1}{\sqrt{1 + x^{2}}} \end{aligned} cosarctanx=1+x2​1​​

这里我们不去严谨的考察反三角函数的定义域值域问题, 而是给出一个形象的证明

考虑一个锐角为 θ=arctan⁡x\theta = \arctan xθ=arctanx 的直角三角形, 我们设直接构成该角的直角边长度为单位1, 那么该角度对边, 也就是另一条直角边, 其长度为 xxx, 从而斜边长度为 1+x2\sqrt{1 + x^{2}}1+x2​, 那么自然有

cos⁡θ=cos⁡arctan⁡x=11+x2\begin{aligned} \cos \theta = \cos \arctan x = \frac{1}{\sqrt{1 + x^{2}}} \end{aligned} cosθ=cosarctanx=1+x2​1​​
